# 1.3.7 출시노트

## 사용자 변경사항
- iOS에서 받는 사람 선택/검색 중 키보드가 입력 영역을 가리던 문제를 개선했습니다.
- iOS에서 나눔다행체 굵은 글씨가 기본 폰트처럼 보이던 문제를 수정했습니다.
- 꿈카드 이미지가 단일 상징보다 더 풍부한 장면과 분위기를 담도록 이미지 생성 프롬프트를 개선했습니다.

## 운영 메모
- 앱 버전: 1.3.7
- Android versionCode: 14
- iOS buildNumber: 12
- 백엔드 배포 시 `IOS_LATEST_VERSION=1.3.7`로 맞추면 iOS 업데이트 안내 기준이 최신 앱 버전과 일치합니다.
