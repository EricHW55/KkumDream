KKUMDREAM Android Emulator 실행 가이드

결론
에뮬레이터에서 앱을 실행하려면 보통 아래 3개가 필요하다.

1. 백엔드 서버 실행
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

2. Metro 서버 실행
   npm start

3. Android 에뮬레이터에 앱 설치 및 실행
   npm run android

즉, uvicorn app.main:app --reload 와 npm start 는 필요하지만, 그것만으로 앱이 에뮬레이터에서 자동 실행되는 것은 아니다.
npm run android 까지 실행해야 React Native 앱이 Android 에뮬레이터에 빌드, 설치, 실행된다.


각 명령의 역할

1. uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

이 명령은 backend 폴더의 FastAPI 서버를 실행한다.
KKUMDREAM 앱은 꿈 카드, 방, 받은 꿈, 보낸 꿈, 로그인 같은 데이터를 백엔드 API에서 가져온다.
따라서 앱 화면이 정상 동작하려면 백엔드 서버가 먼저 켜져 있어야 한다.

실행 위치:
  C:\dev\KkumDream\KKUMDREAM\backend

권장 실행:
  conda activate kkumdream
  alembic upgrade head
  uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

--reload 는 코드가 바뀌면 서버를 자동 재시작하는 개발용 옵션이다.
--host 0.0.0.0 은 같은 PC 안의 Android 에뮬레이터가 백엔드에 접근할 수 있게 열어두는 설정이다.
--port 8000 은 API 서버를 8000번 포트에서 실행한다는 뜻이다.

서버가 정상 실행되면 PC 브라우저에서 아래 주소를 열 수 있어야 한다.
  http://127.0.0.1:8000/docs


2. npm start

이 명령은 mobile 폴더의 React Native Metro 서버를 실행한다.
Metro는 React Native JavaScript/TypeScript 코드를 번들링해서 Android 앱에 전달하는 개발 서버다.

실행 위치:
  C:\dev\KkumDream\KKUMDREAM\mobile

Git Bash 기준 실행:
  cd /c/dev/KkumDream/KKUMDREAM/mobile
  npm start

PowerShell 기준 실행:
  cd C:\dev\KkumDream\KKUMDREAM\mobile
  npm start

이 터미널은 앱 개발 중 계속 켜두는 것이 좋다.
앱이 실행된 뒤 JavaScript 코드가 바뀌면 Metro를 통해 변경 내용이 반영된다.


3. Android Emulator 실행

Android Studio에서 에뮬레이터를 먼저 켠다.

실행 방법:
  Android Studio > Device Manager > 원하는 가상 기기 실행

에뮬레이터가 완전히 부팅된 뒤 다음 단계로 넘어가는 것이 좋다.


4. npm run android

이 명령은 React Native Android 앱을 빌드하고, 켜져 있는 에뮬레이터에 설치한 뒤 실행한다.

실행 위치:
  C:\dev\KkumDream\KKUMDREAM\mobile

Git Bash 기준 실행:
  cd /c/dev/KkumDream/KKUMDREAM/mobile
  npm run android

PowerShell 기준 실행:
  cd C:\dev\KkumDream\KKUMDREAM\mobile
  npm run android

처음 실행할 때는 Android 빌드 시간이 오래 걸릴 수 있다.
이미 앱이 설치되어 있고 Metro가 켜져 있다면, 이후에는 앱을 에뮬레이터에서 직접 다시 열어도 되는 경우가 많다.
하지만 네이티브 의존성, Android 설정, Gradle 설정이 바뀌었다면 npm run android 를 다시 실행하는 것이 안전하다.


권장 실행 순서

터미널 1: 백엔드 서버
  cd C:\dev\KkumDream\KKUMDREAM\backend
  conda activate kkumdream
  alembic upgrade head
  uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

터미널 2: Metro 서버
  cd C:\dev\KkumDream\KKUMDREAM\mobile
  npm start

Android Studio:
  Device Manager에서 Android Emulator 실행

터미널 3: 앱 설치 및 실행
  cd C:\dev\KkumDream\KKUMDREAM\mobile
  npm run android


왜 앱 주소가 10.0.2.2 인가?

모바일 앱 설정은 현재 아래 API 주소를 사용한다.
  http://10.0.2.2:8000/api/v1

Android 에뮬레이터 안에서 localhost 또는 127.0.0.1 은 개발 PC가 아니라 에뮬레이터 자기 자신을 의미한다.
그래서 에뮬레이터에서 개발 PC의 8000번 포트로 접근하려면 10.0.2.2 를 사용한다.

즉, PC에서 백엔드는 아래처럼 보인다.
  http://127.0.0.1:8000

Android 에뮬레이터 안에서는 같은 백엔드가 아래처럼 보인다.
  http://10.0.2.2:8000


자주 헷갈리는 부분

1. uvicorn만 실행하면 앱이 켜지는가?
   아니다. uvicorn은 백엔드 API 서버만 켠다.

2. npm start만 실행하면 앱이 에뮬레이터에 설치되는가?
   아니다. npm start는 Metro 서버만 켠다.

3. 앱을 에뮬레이터에 설치하고 실행하는 명령은 무엇인가?
   npm run android 이다.

4. 백엔드 서버가 꺼져 있으면 어떻게 되는가?
   앱은 켜질 수 있지만 API 호출이 실패해서 로그인, 방 목록, 받은 꿈, 보낸 꿈 같은 기능이 정상 동작하지 않을 수 있다.

5. Metro 서버가 꺼져 있으면 어떻게 되는가?
   개발 모드 앱이 JavaScript 번들을 받아오지 못해 실행 실패 또는 빨간 오류 화면이 나올 수 있다.

6. 에뮬레이터가 먼저 켜져 있어야 하는가?
   npm run android를 실행하기 전에 에뮬레이터가 켜져 있는 것이 가장 안정적이다.


빠른 체크

백엔드 확인:
  http://127.0.0.1:8000/docs

모바일 의존성 확인:
  cd C:\dev\KkumDream\KKUMDREAM\mobile
  npm install

Android 빌드 실행:
  npm run android

정리하면, 개발 중에는 백엔드 터미널, Metro 터미널, 앱 실행 터미널을 분리해서 사용하는 것이 좋다.
백엔드와 Metro는 계속 켜두고, 앱 설치나 재빌드가 필요할 때 npm run android 를 실행하면 된다.
