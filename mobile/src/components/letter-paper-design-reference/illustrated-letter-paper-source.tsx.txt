This file keeps the original React Native illustrated letter-paper layout for
future design edits. It is intentionally saved with a .txt suffix so it is not
compiled by TypeScript or bundled by Metro.


Original render branches:

```tsx
{design.letterPaper === 'moonlit' ? (
  <View pointerEvents="none" style={styles.letterDecorationClip}>
    <MoonCloudLetterDecorations />
  </View>
) : null}
{design.letterPaper === 'butterfly' ? (
  <View pointerEvents="none" style={styles.letterDecorationClip}>
    <FlowerLetterDecorations />
  </View>
) : null}
{design.letterPaper === 'rose' ? (
  <View pointerEvents="none" style={styles.letterDecorationClip}>
    <ButterflyLetterDecorations />
  </View>
) : null}
```
